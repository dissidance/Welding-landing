# НТЦ Автоматизированная сварка

Лендинг ООО «НТЦ Автоматизированная сварка»: сборка, настройка и подключение сварочных аппаратов.

Сайт: https://dissidance.github.io/Welding-landing/

## Исходники

- `index.html` — содержание страницы и SVG-схема сварочного портала.
- `style.css` — оформление под инженерный чертёж, мобильная вёрстка и анимация.
- `script.js` — управление паузой анимации.

## Просмотр

Откройте `index.html` в браузере или запустите статический HTTP-сервер из корня репозитория. Сборка и установка зависимостей не требуются.

Шрифты загружаются из Google Fonts. При отсутствии сети используются системные шрифты.
